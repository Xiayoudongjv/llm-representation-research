# EXP-008 Invariant-constrained Steering

## Research Question

Can invariant-aware selection reduce relational distortion while maintaining transition success?

## Why This Experiment Is Needed

EXP-007 identified beta 0.75 as a stable frontier point. However, different
validity penalties may prefer smaller beta values if they reduce IVS or
perturbation while retaining partial transition success.

## Method

This experiment reuses the EXP-006 invariant metrics and EXP-007 frontier
summary. It does not rerun Qwen. For each source-target pair and each lambda-
gamma setting, it computes:

`constraint_score = target_assignment_rate - lambda * IVS - gamma * relative_perturbation_norm`

The beta with the highest score is compared with the EXP-007 recommended
frontier beta. Candidate values are the discrete beta values already present in
the input CSV files.

## Metrics

- assignment rate
- invariant violation score (IVS)
- RSM Pearson correlation
- relative perturbation norm
- delta IVS versus the baseline frontier
- delta assignment versus the baseline frontier

## Expected Outcomes

### Outcome A

Invariant-constrained selection keeps beta 0.75. The EXP-007 frontier is robust
under additional penalties.

### Outcome B

Selection chooses a smaller beta while keeping high assignment. There may be a
more conservative operating point.

### Outcome C

Smaller beta greatly reduces assignment. Transition success and invariant
preservation are in real tension.

### Outcome D

Selection is highly pair-dependent. Valid transformation strength may require
pair-specific calibration.

## Limitations

- no learned transformation
- no new model run
- selection over discrete beta candidates only
- RSM is only a proxy invariant
- no generation-time evaluation
- no answer-level reasoning evaluation
