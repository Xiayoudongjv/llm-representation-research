# EXP-001: Representation Geometry Baseline

## Goal

Build the first controlled baseline for comparing the geometry of model representations across reasoning-related prompt groups.

## Hypothesis

Prompts within the same semantic group will show more similar last-token representations than unrelated groups.

## Model

Primary: `Qwen/Qwen3-1.7B`  
Fallback: `TinyLlama/TinyLlama-1.1B-Chat-v1.0`

## Prompt Groups

Twelve short English prompts are divided into four groups: logic, causality, analogy, and definition, with three prompts per group.

## Method

Load each prompt, run a forward pass with `output_hidden_states=True`, select the requested layer (the final hidden-state tensor by default), and extract the last-token vector. Compute a cosine similarity matrix and a two-dimensional sklearn PCA projection.

## Metrics

- Pairwise cosine similarity
- PCA coordinates
- PCA explained variance ratio

## Expected Output

`results/exp001/representations_metadata.json`, `cosine_similarity.csv`, `pca_coords.csv`, and `pca_plot.png`. Full hidden-state tensors are not saved.
