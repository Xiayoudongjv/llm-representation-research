# EXP-011 Expanded Answer-level Dataset

## Motivation

EXP-009 had only 24 answer-level prompts, and EXP-010 was inconclusive at the
four-group level. EXP-011 expands the behavioral evaluation set before any
intervention work.

## Design

The dataset has 80 deterministic short-answer questions: 20 each for logic,
causality, analogy, and definition. Items include acceptable answer lists and
use a case-insensitive containment scoring rule. The design avoids
multiple-choice, open-ended, arithmetic-heavy, and ambiguous questions.

## Validation

The validation script checks JSON structure, total size, required fields,
unique IDs and questions, balanced group counts, lowercase acceptable answers,
required answer/scoring fields, duplicate acceptable answers, normalized
question duplicates, and the expected EXP-011 ID format. It also warns when an
acceptable answer is two characters or shorter.

Run the static semantic and scoring audit with:

```bash
python experiments/exp011/audit_dataset_quality.py
```

## Status

Dataset design, validation, and a static quality audit only. No model run has
been performed. Before model evaluation, the scoring configuration was hardened
to use boundary-aware short-answer matching rather than raw substring matching.
