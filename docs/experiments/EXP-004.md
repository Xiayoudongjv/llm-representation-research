# EXP-004 Static Steering Vector Baseline

## Research Question

Can a static centroid-difference vector shift source-group representations
toward a target-group region?

## Hypothesis

If task-associated geometry is meaningful, adding the target-minus-source
centroid direction should increase similarity to the target group and reduce
relative similarity to the source group.

## Model

`Qwen/Qwen3-1.7B`

## Layer

Default layer 16, selected because EXP-003 found the strongest controlled
separation and paraphrase retention around layer 16.

## Method

Extract last-token hidden states at the selected layer, compute group
centroids, and define `v = target_centroid - source_centroid`. Normalize `v`,
then apply `h' = h + alpha * v` to source-group representations. Evaluate
cosine similarities and nearest-centroid movement across alpha values.

This is a representation-level static steering baseline, not a generation-time
activation intervention.

## Metrics

- Mean similarity to source centroid
- Mean similarity to target centroid
- Target-minus-source similarity
- Target assignment rate

## Expected Outcomes

### Outcome A

Target similarity increases with alpha.

Interpretation: static representation-level steering moves source
representations toward the target region.

### Outcome B

Movement is weak or unstable.

Interpretation: the centroid direction may not capture robust task-transition
structure.

### Outcome C

Negative alpha moves away from the target or toward the source.

Interpretation: directionality may be meaningful.

## Limitations

- Representation-level steering only.
- No generation-time behavioral evaluation.
- Small prompt set.
- The centroid method is simple.
- This does not prove reasoning improvement.
- Relational invariants are not defined yet.
