# EXP-007 Transition Validity Frontier

## Research Question

What steering strength provides the best transition-validity trade-off?

## Why This Experiment Is Needed

EXP-006 showed that increasing beta improves transition success but increases
invariant violation. A valid transformation should balance success and
relational preservation.

## Inputs

This analysis uses `results/exp006/transition_invariant_tradeoff.csv` and
`results/exp006/invariant_pair_summary.csv`.

## Method

Load the EXP-006 transition/invariant data, compute exploratory validity scores,
identify the minimum beta for full assignment, and select a recommended beta
for each ordered pair. The recommendation prefers the lowest-IVS beta among
settings with assignment rate 1.0, then falls back to assignment rate 0.5 or
the best balanced score.

## Metrics

- Target assignment rate
- Invariant violation score
- RSM Pearson correlation
- Relative perturbation norm
- Success-minus-violation score
- Balanced validity score
- Recommended beta

The scalar scores are heuristic exploratory summaries, not final theoretical
definitions.

## Expected Outcomes

### Outcome A

Most pairs recommend beta 0.75.

Interpretation: beta 0.75 may be a good transition-validity operating point.

### Outcome B

Recommended beta varies by pair.

Interpretation: transition validity is pair-dependent.

### Outcome C

Large beta values maximize naive success but not balanced validity.

Interpretation: stronger steering is not necessarily more valid.

## Limitations

- Validity scores are heuristic.
- RSM correlation is only a proxy invariant.
- Nearest-centroid assignment is not reasoning correctness.
- No generation-time evaluation.
- One model.
- Small prompt set.
- Lambda hyperparameter choices are exploratory.
