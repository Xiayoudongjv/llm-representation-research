# EXP-005 Multi-pair Calibrated Steering Generalization

## Research Question

Does calibrated centroid steering generalize across multiple task-group
transitions?

## Hypothesis

If task-associated representation geometry supports transition-like movement,
calibrated centroid steering should increase target similarity across multiple
ordered source-target pairs.

## Why This Experiment Is Needed

EXP-004B tested only logic to causality. A single pair is insufficient to claim
generality, and transitions may be asymmetric.

## Model

`Qwen/Qwen3-1.7B`

## Layer

Layer 16, selected because EXP-003 found strongest controlled separation and
paraphrase retention around layer 16.

## Prompt Set

Reuse the controlled 24-prompt set from EXP-003 without modification.

## Method

Compute centroids for the four groups, calculate a calibrated delta for each
ordered source-target pair, and apply `h' = h + beta * delta` to source-group
representations. Evaluate target similarity, nearest-centroid assignment, and
relative perturbation across beta values.

## Metrics

- Target assignment rate
- Target-minus-source similarity
- Minimum beta for target assignment >= 0.5
- Minimum beta for target assignment = 1.0
- Asymmetry score
- Relative perturbation norm

## Expected Outcomes

### Outcome A

Most transitions succeed at moderate beta.

Interpretation: calibrated centroid steering may be a strong
representation-level baseline.

### Outcome B

Only some transitions succeed.

Interpretation: representation transitions are pair-dependent or asymmetric.

### Outcome C

Most transitions require very large perturbations.

Interpretation: centroid steering is possible but may be out-of-distribution.

### Outcome D

Transitions fail broadly.

Interpretation: simple centroid directions may be insufficient, motivating
learned task-conditioned transformations.

## Limitations

- Representation-level only.
- No generation-time behavior evaluation.
- Small prompt set.
- One model.
- Layer 16 only.
- Nearest-centroid reassignment is not reasoning improvement.
- Large beta may produce out-of-distribution representations.
