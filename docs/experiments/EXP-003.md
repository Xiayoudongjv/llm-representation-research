# EXP-003 Lexical and Paraphrase Control

## Research Question

Do task-associated representation geometry signals remain when lexical and
template variation are controlled?

## Hypothesis

If geometry reflects task-relevant relational structure rather than only
surface wording, same-group paraphrases should remain relatively close across
layers while different groups remain more separated.

## Why This Control Is Needed

EXP-001 and EXP-002 may be confounded by lexical overlap, prompt length, and
prompt template. EXP-003 includes original-style and paraphrased prompts in
each task group to test the stability of the observed structure.

## Model

`Qwen/Qwen3-1.7B`

## Prompt Design

There are 24 short English prompts: six each for logic, causality, analogy,
and definition. Each group contains three original-style and three paraphrase
prompts. Wording is varied and the original EXP-001/EXP-002 prompt files are
not changed.

## Metrics

- Within similarity
- Between similarity
- Separation score
- Silhouette score
- Same-group cross-variant similarity
- Same-variant cross-group similarity
- Paraphrase retention score
- PCA explained variance and centroid distances

The paraphrase retention score is same-group cross-variant similarity minus
same-variant cross-group similarity. It is a rough control metric, not proof
of task-level abstraction.

## Expected Outcomes

### Outcome A

Task-group structure remains after paraphrasing.

Interpretation: evidence is more consistent with task-associated
representation geometry.

### Outcome B

Structure collapses after paraphrasing.

Interpretation: earlier EXP-001/EXP-002 geometry may have been driven by
lexical/template confounds.

### Outcome C

Only some groups survive paraphrase control.

Interpretation: some task types may have more stable representations than
others.

## Limitations

- Small prompt set.
- Prompts are still manually designed.
- Paraphrase quality is not independently verified.
- Only the last-token representation is analyzed.
- Only one model is evaluated.
