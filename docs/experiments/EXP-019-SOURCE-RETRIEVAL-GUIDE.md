# EXP-019 Source Retrieval Guide

This guide is for a future pilot of independent source-card collection. It
does not authorize retrieval in this task and source cards must not contain
final response wording.

## Query templates

### Logic

Find one simple, uncontroversial pair of factual premises from an approved
source that can support a basic logical inference. Return only the source and
premise structure; do not write the final dataset response.

### Causality

Find one simple cause-effect or mechanism relation from an approved
educational source. Return source, cause, effect, and mechanism if present;
do not compose the final response.

### Analogy

Find two simple independently supported relations with a comparable functional
or structural relationship. Return only the relation pairs; do not compose an
analogy sentence.

### Definition

Find one simple concept definition from an approved reference. Return the
concept, broader category, and key defining property; do not write the final
response.

## Retrieval quality

Prefer simple, uncontroversial, general-education facts that are independently
verifiable and suitable for concise self-contained responses. Reject uncertain,
contested, jurisdiction-dependent, political, or opinion-based claims where
avoidable. Store metadata and compact factual extraction only; do not store
long copyrighted passages.

## Source whitelist

Preferred Tier 1 sources include Britannica, Khan Academy, OpenStax, NASA,
NOAA, NIH/NCBI educational pages, USGS, Smithsonian educational resources,
university educational pages, Cambridge Dictionary, and Merriam-Webster.
Wikipedia is permitted as Tier 2 general reference but must not dominate.
Do not use Reddit, Quora, Zhihu, personal blogs, commercial SEO articles,
AI-generated content farms, anonymous forums, social media, or marketing pages
as primary provenance.

The pilot target is five source cards per class (20 total): logic 5,
causality 5, analogy 5, and definition 5. This is only a quota plan; no
cards are retrieved or created here.
