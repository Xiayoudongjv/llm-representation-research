# EXP-002 Layer-wise Representation Geometry

## Research Question

At what Transformer depth does task-related representation geometry emerge?

## Hypothesis

If EXP-001 grouping reflects increasingly abstract internal representations
rather than only lexical similarity, within-group separation from
between-group representations should change systematically across depth.

## Model

`Qwen/Qwen3-1.7B`

## Dataset / Prompts

The exact 12-prompt set from EXP-001 is reused unchanged: three prompts each
from logic, causality, analogy, and definition groups.

## Layers

Layers `0, 4, 8, 12, 16, 20, 24, 28` are evaluated.

## Representation Extraction

Each prompt is tokenized and processed with one forward pass using
`output_hidden_states=True`. For every selected layer, the last-token hidden
state is copied to CPU and converted to float32. Full representation tensors
are not saved.

## Metrics

- Within-group and between-group cosine similarity
- Separation score: within-group similarity minus between-group similarity
- Cosine-distance silhouette score
- PCA explained variance and per-layer PCA plots
- Pairwise cosine distances between group centroids

## Confound Diagnostics

Token count is recorded for every prompt. A preliminary Pearson correlation is
computed between token count and the Euclidean norm of the final-layer
last-token representation. This diagnostic does not eliminate lexical or
template confounds.

## Expected Outcomes

### Outcome A

Within-between separation increases with depth.

Possible interpretation: task-related geometry becomes more organized in
deeper layers.

### Outcome B

Separation is already strong at shallow layers.

Possible interpretation: lexical/token-level features may explain a substantial
part of the clustering.

### Outcome C

Separation is unstable or disappears.

Possible interpretation: EXP-001 final-layer clustering may not represent a
robust layer-wise structure.

These outcomes do not prove semantic abstraction.

## Limitations

- Only 12 prompts are used.
- Lexical and template confounds may influence geometry.
- Only the last-token representation is analyzed.
- Only one model is evaluated.
- PCA is a visualization, not proof of cluster structure.
