# EXP-006 Relational Invariant Score

## Research Question

Does calibrated centroid steering preserve within-source relational structure
while moving representations toward target regions?

## Hypothesis

If calibrated steering is a valid representation transformation, it should move
representations toward target regions while preserving the source group's
internal pairwise similarity structure.

## Why This Experiment Is Needed

EXP-005 showed successful nearest-centroid transitions, but nearest-centroid
reassignment does not prove relational preservation.

## Model

`Qwen/Qwen3-1.7B`

## Layer

Layer 16, selected based on EXP-003 and EXP-005.

## Prompt Set

Reuse the 24-prompt controlled set from EXP-003.

## Method

Extract last-token hidden states, compute the source-group RSM before steering,
apply calibrated centroid steering for each ordered pair and beta, and compute
the source-group RSM after steering. Compare the two RSMs using Pearson and
Spearman correlations and a Frobenius distance.

## Metrics

- RSM Pearson correlation
- RSM Spearman correlation
- Invariant Violation Score = `1 - RSM Pearson`
- RSM Frobenius distance
- Target assignment rate
- Relative perturbation norm

## Expected Outcomes

### Outcome A

Assignment improves while invariant violation remains low.

Interpretation: the transition may preserve relational structure.

### Outcome B

Assignment improves but invariant violation increases.

Interpretation: the transition succeeds geometrically but distorts internal
relationships.

### Outcome C

The invariant is preserved trivially for all beta.

Interpretation: the chosen invariant proxy may be insensitive.

### Outcome D

The invariant is unstable or noisy.

Interpretation: RSM correlation may be unreliable for small source groups.

## Limitations

- RSM correlation is only a proxy invariant.
- Small group size: only 6 prompts per group.
- Only the last-token representation is analyzed.
- No generation-time evaluation.
- No reasoning correctness evaluation.
- Centroid steering may create out-of-distribution states.
